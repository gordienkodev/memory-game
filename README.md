# Memory Game

Memory Game — браузерная игра на поиск пар. Игрок открывает карточки, запоминает их расположение и старается найти все совпадения за минимальное количество ходов. Результаты сохраняются.

## Возможности

- 16 перемешанных карточек с 8 парами
- счётчик ходов и найденных пар
- модальное окно победы с итоговым результатом
- таблица лидеров с 10 лучшими результатами, сохранёнными в localStorage
- новая игра без перезагрузки страницы

## Локальный запуск

Откройте файл `index.html` в браузере.
